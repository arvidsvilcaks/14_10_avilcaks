## Ko meklē

| Ieraksts | Lauki | Kas redz |
| --- | --- | --- |
| Organizācijas | nosaukums, reģ. nr. | Visi |
| Kontaktpersonas | vārds, amats, e-pasts, tālrunis | Visi (sarakstā bez e-pasta un tālruņa; tie ir kartītē) |
| Mijiedarbības | kopsavilkums, organizācijas nosaukums | Darbinieks — savas; vadītājs — visas |
| Pieprasījumi | apraksts, organizācijas nosaukums | Darbinieks — savi; vadītājs — visi |
| Uzdevumi | nosaukums, organizācijas nosaukums | Darbinieks — savi; vadītājs — visi |

Redzamība atkārto sadaļu sarakstu noteikumus (N3), tāpēc meklēšana nedod piekļuvi vairāk datiem nekā saraksti.

## Detalizētās apakšprasības

| ID | Apakšprasība |
| --- | --- |
| F6.1 | Meklēšana neatšķir lielos un mazos burtus un garumzīmes / mīkstinājuma zīmes („zarins” atrod „Zariņš”) |
| F6.2 | Vaicājums īsāks par 2 rakstzīmēm neko nemeklē; lapā ir paskaidrojums |
| F6.3 | Rezultāti sagrupēti pa ierakstu veidiem; katrai grupai ir `h2` ar skaitu un tabula ar `caption` |
| F6.4 | Kopējais rezultātu skaits paziņots elementā `role="status"` |
| F6.5 | Tukšai grupai teksts „Nav atrasts.” |
| F6.6 | Organizāciju un kontaktu rezultāti ved uz organizācijas kartīti |
| F6.7 | Navigācijā ir saite „Meklēt”; paneļa meklēšanas lauks sūta uz `/meklet` |
| F6.8 | `GET /meklet?q=` ar JSON atgriež `MeklesanasRezultati` |

## Pieņemšanas kritēriji

| # | Gadījums | Gaidāmais rezultāts |
| --- | --- | --- |
| 1 | „ziemelu” | Atrod „SIA Ziemeļu Būve”, tās mijiedarbības un pieprasījumus |
| 2 | Darbinieks B meklē A mijiedarbību tekstu | Neatrod (organizāciju gan atrod) |
| 3 | „e” | Tukši rezultāti un paskaidrojums |
| 4 | Nepieslēdzies | 401 / novirzīšana uz pieslēgšanos |

## Tehniskā realizācija (N4)

- `crm/meklesana.py`; izmanto esošās `atlasit` / `meklet` funkcijas un `normalizet` no F1.
- Filtrēšana Python pusē — ar prototipa datu apjomu (desmiti–simti ierakstu) pietiekami ātri; N4 tests pārbauda < 1 s ar sākumdatiem. Ja datu būs daudz vairāk, normalizētās kolonnas un SQL `LIKE` jāpievieno katrai tabulai.
- Šablons `templates/meklesana/rezultati.html`; testi `test_f6_*`.
