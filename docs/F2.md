# F2 — Kontaktpersonas pie organizācijas: prasības apraksts

Oct 14, 2026 · @Arvīds Vilčaks

## Pamatinformācija

Kontaktpersona ir cilvēks organizācijā, ar kuru pašvaldības darbinieks sazinās. Kontaktpersonas glabā tikai pie organizācijas un rāda organizācijas kartītē.

| Lauks | Vērtība |
| --- | --- |
| ID | F2 |
| Nosaukums | Kontaktpersonas pie organizācijas |
| Veids | Funkcionālā prasība |
| Statuss | Izpildīts (bez CR, 2026-10-14) |
| Atkarīga no | F0 (pieslēgšanās), F1 (organizācijas), N3 (lomas) |
| Izmanto | F6 (meklēšana) |
| Jāatbilst | N1 (pieejamība), N2 (personas dati), N4 (tehnoloģijas) |

## Mērķis un lietotāji

| Loma | Ko var darīt | Nolūks |
| --- | --- | --- |
| Darbinieks | Skatīt visu organizāciju kontaktpersonas; pievienot, labot un dzēst kontaktpersonas organizācijām, kurām ir atbildīgais | Zināt, kam zvanīt vai rakstīt |
| Vadītājs | Visu, ko darbinieks, visām organizācijām | Uzturēt datu kvalitāti |

Tiesības sakrīt ar organizācijas labošanas tiesībām F1: atbildīgais darbinieks vai vadītājs.

## Lauki

| Lauks | Obligāts | Noteikumi |
| --- | --- | --- |
| Vārds, uzvārds | Jā | 1–100 rakstzīmes |
| Amats | Nē | līdz 100 rakstzīmēm |
| E-pasts | Nē | derīga adrese; saglabā mazajiem burtiem |
| Tālrunis | Nē | cipari, atstarpes, `+ ( ) -`; līdz 30 rakstzīmēm |

## Detalizētās apakšprasības

| ID | Apakšprasība | Saistība |
| --- | --- | --- |
| F2.1 | Organizācijas kartītē ir bloks „Kontaktpersonas” (pirms mijiedarbībām) ar tabulu: vārds, amats, e-pasts (`mailto:`), tālrunis (`tel:`) | F1 |
| F2.2 | Atbildīgais vai vadītājs var pievienot kontaktpersonu ar formu; pēc saglabāšanas novirza uz kartīti (PRG, 303) | F1, N3 |
| F2.3 | Kontaktpersonu var labot; nenorādītie neobligātie lauki tiek notīrīti | N2 (labošana) |
| F2.4 | Kontaktpersonu var dzēst; dzēšana ir neatgriezeniska, un dati uzreiz pazūd no kartītes un meklēšanas | N2 (dzēšana) |
| F2.5 | Citam darbiniekam pogas „Pievienot”, „Labot”, „Dzēst” nav redzamas, un serveris atbild 403 | N3 |
| F2.6 | Kļūdainā formā redzams kļūdu kopsavilkums (`role="alert"`) un kļūda pie lauka | N1 |
| F2.7 | Panelī (F9) kontaktpersonu e-pastus un tālruņus nerāda | N2 |

## Pieņemšanas kritēriji

| # | Gadījums | Gaidāmais rezultāts |
| --- | --- | --- |
| 1 | Atbildīgais pievieno kontaktu ar vārdu | 201 / 303; kontakts redzams kartītē |
| 2 | Tukšs vārds, nederīgs e-pasts vai tālrunis | 422, lauka kļūda |
| 3 | Cits darbinieks mēģina pievienot, labot vai dzēst | 403 |
| 4 | Vadītājs dzēš jebkuru kontaktu | 204 |
| 5 | Neeksistējoša organizācija vai kontakts | 404 |
| 6 | Panelis pēc kontakta pievienošanas | Kontakta e-pasts un tālrunis panelī nav redzami |

## Personas dati (N2)

- Laukus ierobežo ar darba kontaktinformāciju; formā ir atgādinājums neievadīt liekus datus.
- Kontaktu saraksta nolasīšana (kartīte vai `GET /organizacijas/{id}/kontakti`) tiek ierakstīta piekļuves žurnālā.
- Dzēšot organizāciju datubāzē, tās kontakti tiek dzēsti kaskādē (`ON DELETE CASCADE`).

## Tehniskā realizācija (N4)

- Modulis `crm/kontakti.py`, tabula `kontaktpersonas`, šabloni `templates/kontakti/`.
- JSON: `GET/POST /organizacijas/{id}/kontakti`, `PUT/DELETE /kontakti/{id}` (aprakstīti `docs/openapi.yaml`).
- HTML formas: `GET /organizacijas/{id}/kontakti/jauns`, `GET/POST /kontakti/{id}/labot`, `POST /kontakti/{id}/dzest`.
- Kartītes bloks pievienots ar esošo `KARTITES_PAPILDINAJUMI` mehānismu (kā F3, F4).
- Testi: `tests/test_prasibas_f2_n4.py` (`test_f2_*`).
