# N3 — Lomas: prasības apraksts

Oct 14, 2026 · @Arvīds Vilčaks

## Pamatinformācija

N3 nosaka divas lomas — „Darbinieks” un „Vadītājs”. Loma nosaka, ko lietotājs redz un drīkst darīt, un to pārbauda serverī katrā pieprasījumā, nevis tikai paslēpj ekrānā.

| --- | --- |
| ID | N3 |
| Nosaukums | Lomas |
| Veids | Nefunkcionālā prasība |
| Statuss | Izpildīts (CR-5) |
| Atkarīga no | F0 (pieslēgšanās / reģistrēšanās) |
| Izmanto | F1, F3, F4, F5, F9 (datu filtrēšana un tiesības) |
| Jāatbilst | N1 (pieejamība), N2 (personas dati), N4 (tehnoloģijas) |

## Mērķis un lietotāji

| Loma | Vērtība datubāzē | Tiesības |
| --- | --- | --- |
| Darbinieks | `darbinieks` | Strādā ar saviem datiem: savas mijiedarbības un pieprasījumi; labo tikai organizācijas, kurām ir atbildīgais |
| Vadītājs | `vaditajs` | Redz visu darbinieku datus, labo visas organizācijas un pieprasījumus, maina atbildīgo darbinieku un lietotāju lomas |

## Lomu ietekme uz funkcijām

| Funkcija | Darbinieks | Vadītājs |

## Pieejamība (N1)

- Mācību režīma pārslēgšana ir parasta poga galvenē ar pilnu tekstu „Mācību režīms: skatīt kā vadītājam / darbiniekam”, sasniedzama ar tastatūru.
- Loma redzama tekstā, nevis tikai ar krāsu vai ikonu.

## Personas dati (N2)

- Darbinieks nevar iegūt citu darbinieku mijiedarbības un pieprasījumus sarakstā, mainot URL parametrus — filtrs tiek pielikts serverī.
- Lomu nevar mainīt caur sesijas sīkdatni, jo sesijā loma netiek glabāta.

## Tehniskā realizācija (N4)

- **Maršruti:** `PATCH /lietotaji/{id}/loma` (200/403/404/409/422), `POST /macibu-rezims/loma` (200/303/403/422); abi aprakstīti `docs/openapi.yaml`.
- **Atkarības:** `crm/auth.py` — `Lietotajs.ir_vaditajs`, `Pieslegts`, `pieslegts_vaditajs` / `Vaditajs` (403 nevadītājam); `LOMU_NOSAUKUMI` — Jinja2 globālais mainīgais.
- **Filtrēšana:** moduļi izmanto `None if lietotajs.ir_vaditajs else lietotajs.id` kā atbildīgā/darbinieka filtru (`crm/mijiedarbibas.py`, `crm/pieprasijumi.py`, `crm/panelis.py`).
- **Faili:** `crm/lomas.py`, `crm/auth.py`, `crm/sakumdati.py`, `crm/db.py` (migrācija), `crm/templates/base.html` (galvene, mācību režīma poga).
- **Testi:** `tests/test_cr5_lomas.py`.
