## Mērķis un lietotāji

Panelis ļauj dienas sākumā redzēt, kas jādara un kas kavējas, nemeklējot pa vairākām sadaļām. „Lietotāja līmenis” nozīmē: saturu filtrē pēc pieslēgtā lietotāja un viņa lomas.

| Loma | Ko redz | Nolūks |
| --- | --- | --- |
| Darbinieks | Tikai savus datus: organizācijas, kurām viņš ir atbildīgais, savus uzdevumus, pieprasījumus un mijiedarbības | Plānot dienu un nepalaist garām termiņus |
| Vadītājs | Visu darbinieku datus un kopējos rādītājus, kopā ar īsu aktivitātes kopsavilkumu | Uzraudzīt slodzi un kavējumus, pāriet uz F7 pārskatu |

## Pieejamība (N1)

Panelis ir galvenā ceļa daļa, tāpēc tam piemēro pilnas EN 301 549 / WCAG 2.2 AA prasības.

- **Struktūra:** viens `h1` „Vadības panelis”, katram blokam `h2`; lapai ir orientieri `header`, `nav`, `main`, `footer`.
- **Kavējumi:** kavētais pieprasījums marķēts ar vārdu „Kavēts”, nevis tikai ar sarkanu krāsu (kā F4).
- **Tabulas:** katrai tabulai ir `caption` un virsrakstu šūnām `th scope` (kā F6).
- **Rādītāju kartītes:** saites teksts ir pilns, piemēram, „3 kavētie pieprasījumi”, nevis tikai „3”.
- **Diagramma:** ja vadītāja blokā ir diagramma, blakus ir tabula ar tiem pašiem datiem (kā F7).
- **Tastatūra:** visas darbības veicamas ar tastatūru; fokuss ir redzams; tabulēšanas secība atbilst vizuālajai.
- **Mērogs:** 200 % mērogā bloki kārtojas vienā kolonnā bez horizontālas ritināšanas.
- **Kontrasts:** tekstam vismaz 4,5:1, lielam tekstam un ikonām vismaz 3:1.
- **Paziņojumi:** ziņa „Uzdevums atzīmēts kā izpildīts” atrodas elementā ar `role="status"`, lai to nolasītu ekrāna lasītājs.
- **Pārbaude:** axe skenēšanā nav kritisko (critical) un nopietno (serious) kļūdu.

## Personas dati (N2) un MI

Panelis rāda tikai to, kas vajadzīgs darba plānošanai; pilni personas dati paliek organizācijas kartītē.

**Personas dati (VDAR)**

- Panelī nerāda kontaktpersonu e-pastus un tālruņus; redzams tikai organizācijas nosaukums un, ja vajadzīgs, kontaktpersonas vārds.
- Mijiedarbību blokā rāda datumu, veidu un organizāciju, bet ne kopsavilkuma tekstu.
- Paneļa atvēršana netiek ierakstīta piekļuves žurnālā; pāreja no paneļa uz kartīti tiek ierakstīta (N2).
- Dzēsti kontakti un to dati nekavējoties pazūd arī no paneļa.
- Darbinieks nevar iegūt citu darbinieku datus, mainot URL vai formas parametrus (F9.3).

**Mākslīgais intelekts**

- Ja panelī rāda MI-1 ieteikto nākamo soli, tas ir marķēts „Ģenerēts ar MI” un rādīts tikai pēc darbinieka apstiprinājuma.
- MI-2 prioritizāciju panelī nerāda, kamēr nav pieņemts lēmums „būvēt vai nē”.
- Panelis pats nepieņem automatizētus lēmumus par organizācijām vai personām.

## Tehniskā realizācija (N4)

Panelis ir FastAPI maršruts ar Jinja2 šablonu; dati nāk no F1, F3, F4 un F5 SQLite tabulām, panelim jaunas tabulas nav vajadzīgas.

- **Maršruti:** `GET /panelis` rāda paneli (HTML); `GET /api/panelis` atgriež tos pašus datus JSON formātā un ir aprakstīts `docs/openapi.yaml`; `POST /uzdevumi/{id}/izpildits` atzīmē uzdevumu un novirza atpakaļ uz `/panelis` (POST–redirect–GET, 303).
- **Novirzīšana:** F0 pēc veiksmīgas pieslēgšanās atgriež `RedirectResponse(request.url_for("panelis"), status_code=303)`; sākumlapa `/` pieslēgtu lietotāju arī novirza uz `/panelis`.
- **Sesija:** glabā lietotāja ID; lomu nolasa no datubāzes un pārbauda katrā pieprasījumā.
- **Vaicājumi:** visi parametrizēti (`?`); darbiniekam katrs vaicājums satur `WHERE atbildigais_id = ?`, vadītājam šī filtra nav.
- **Piederības pārbaude:** uzdevuma atzīmēšana pārbauda, vai uzdevums pieder lietotājam; ja nē, atbilde ir 403.
- **Šabloni:** `templates/panelis.html` paplašina `base.html`; katrs bloks ir atsevišķā `include` failā.
- **Datums:** „šodien” nozīmē datumu laika joslā Europe/Riga.
- **Ātrums:** ar sākumdatiem (10 organizācijas, 20 kontakti, 30 mijiedarbības) lapa ielādējas ātrāk par 1 s.

```python
def panela_dati(lietotajs: Lietotajs) -> dict:
    filtrs = None if lietotajs.loma == "vaditajs" else lietotajs.id
    dati = {
        "uzdevumi": uzdevumi_sodien(lietotajs.id),
        "pieprasijumi": kavetie_un_tuvakie(filtrs, dienas=3),
        "mijiedarbibas": pedejas_mijiedarbibas(filtrs, limit=5),
    }
    if lietotajs.loma == "vaditajs":
        dati["aktivitate"] = aktivitate_pa_darbiniekiem(dienas=7)
    return dati


@app.get("/panelis", response_class=HTMLResponse, name="panelis")
def panelis(request: Request, lietotajs: Lietotajs = Depends(pieslegts_lietotajs)):
    return templates.TemplateResponse(
        request, "panelis.html", {"lietotajs": lietotajs, **panela_dati(lietotajs)}
    )


@app.get("/api/panelis")
def api_panelis(lietotajs: Lietotajs = Depends(pieslegts_lietotajs)) -> PanelisAtbilde:
    return PanelisAtbilde(lietotajs=lietotajs, **panela_dati(lietotajs))
```
