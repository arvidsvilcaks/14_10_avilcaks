# F1 — Organizācijas: izveidot, rediģēt, meklēt: prasības apraksts

Oct 14, 2026 · @Arvīds Vilčaks

## Pamatinformācija

Organizācija ir CRM pamatieraksts, pie kura piesaista mijiedarbības (F3) un pieprasījumus (F4). Katrai organizācijai ir viens atbildīgais darbinieks. Organizācijas kartīte ir mērķis F9 saitēm (F9.8).

| Lauks | Vērtība |
| --- | --- |
| ID | F1 |
| Nosaukums | Organizācijas: izveidot, rediģēt, meklēt |
| Veids | Funkcionālā prasība |
| Statuss | Izpildīts (CR-6) |
| Atkarīga no | F0 (pieslēgšanās), N3 (lomas) |
| Izmanto | F3, F4 (bloki organizācijas kartītē), F9 (saites, ātrā darbība) |
| Jāatbilst | N1 (pieejamība), N2 (personas dati), N4 (tehnoloģijas) |

## Mērķis un lietotāji

| Loma | Ko var darīt | Nolūks |
| --- | --- | --- |
| Darbinieks | Skatīt un meklēt visas organizācijas; izveidot jaunu (kļūst par atbildīgo); labot tikai tās, kurām ir atbildīgais | Uzturēt savu organizāciju datus |
| Vadītājs | Viss, ko darbinieks, un labot jebkuru organizāciju, mainīt atbildīgo darbinieku | Sadalīt organizācijas starp darbiniekiem |

Lauki: nosaukums (obligāts, 1–200 rakstzīmes), reģistrācijas numurs (nav obligāts, līdz 20 rakstzīmēm, unikāls), atbildīgais darbinieks.

## Pieejamība (N1)

- Sarakstam ir tabula ar `caption` (piem., „Meklēšanas „…” rezultāti: 3”), virsrakstu šūnām `th scope`, nosaukums ir rindas virsraksts ar saiti uz kartīti.
- Meklēšanas forma ar `role="search"` un redzamu etiķeti „Meklēt pēc nosaukuma”.
- Tukšs meklēšanas rezultāts paziņots ar `role="status"` un piedāvā saiti izveidot jaunu organizāciju.
- Formās kļūdu kopsavilkums ar `role="alert"`, laukiem `aria-invalid` / `aria-describedby`.

## Personas dati (N2)

- Organizācijai glabā tikai juridiskus datus (nosaukums, reģ. nr.) un atbildīgā darbinieka ID; kontaktpersonas ir F2 apjomā.
- Visi vaicājumi parametrizēti; `UPDATE` kolonnu nosaukumi ņemti tikai no validētā modeļa laukiem.

## Tehniskā realizācija (N4)

- **Maršruti:** `GET /organizacijas?q=` (HTML vai JSON pēc `Accept`), `POST /organizacijas` (201/409/422), `GET /organizacijas/{id}` (200/404), `PATCH /organizacijas/{id}` (200/403/404/409/422) — aprakstīti `docs/openapi.yaml`; HTML palīgmaršruti `GET /organizacijas/jauna`, `GET|POST /organizacijas/{id}/labot` (forma nevar sūtīt PATCH).
- **Meklēšana:** kolonna `nosaukums_meklesanai` glabā `normalizet()` rezultātu (NFKD bez diakritiskajām zīmēm, `casefold`); meklē ar `LIKE ? ESCAPE '\'`.
- **Paplašināmība:** `KARTITES_PAPILDINAJUMI` — saraksts, kurā F3 un F4 reģistrē savus kartītes blokus.
- **Faili:** `crm/organizacijas.py`, `crm/templates/organizacijas/saraksts.html`, `kartite.html`, `forma.html`; tabula `organizacijas` ar indeksu pēc `atbildigais_id`.
- **Testi:** `tests/test_cr6_organizacijas.py`.
