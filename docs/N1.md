# N1 — Pieejamība: prasības apraksts

Oct 14, 2026 · @Arvīds Vilčaks

## Pamatinformācija

Visām lapām jāatbilst EN 301 549 / WCAG 2.2 AA. N1 ir šķērsprasība: to piemēro katrai funkcionālajai prasībai, un F8 publicē atbilstības paziņojumu.

| Lauks | Vērtība |
| --- | --- |
| ID | N1 |
| Nosaukums | Pieejamība |
| Veids | Nefunkcionālā prasība |
| Statuss | Izpildīts (automātiskās struktūras pārbaudes; axe skenēšana — manuāli, sk. F8) |
| Attiecas uz | F0–F9, MI-1, MI-2 |

## Prasības un realizācija

| ID | Prasība | Kā realizēts |
| --- | --- | --- |
| N1.1 | Valoda | `<html lang="lv">` |
| N1.2 | Orientieri | `header`, `nav` (ar `aria-label`), `main id="saturs"`, `footer` — `base.html` |
| N1.3 | Pāreja uz saturu | Saite „Pāriet uz saturu”, redzama fokusā |
| N1.4 | Virsraksti | Viens `h1` lapā; blokiem `h2` ar `aria-labelledby` |
| N1.5 | Tabulas | Katrai `caption`; visām `th` — `scope` |
| N1.6 | Formas | Katram laukam `label for`; palīdzība un kļūdas ar `aria-describedby`; `aria-invalid`; kļūdu kopsavilkums `role="alert"` ar saitēm uz laukiem |
| N1.7 | Paziņojumi | Darbību rezultāti `role="status"` (uzdevums izpildīts, kontakts dzēsts, meklēšanas rezultātu skaits) |
| N1.8 | Ne tikai krāsa | Atzīmes ar tekstu: „Kavēts”, „Atgādinājums”, „Ģenerēts ar MI” |
| N1.9 | Pogas sarakstos | Pogām un saitēm rindās slēpts konteksts (`.slepts`), piemēram, „Dzēst: Anna Ozola” |
| N1.10 | Fokuss | `:focus-visible` 3 px kontūra |
| N1.11 | Kontrasts | Krāsu tokeni `stils.css` ≥ 4,5:1 |
| N1.12 | Mērogs | Elastīgs izkārtojums (`flex-wrap`), tabulas `overflow-x: auto` ietvarā |
| N1.13 | Meklēšana | Formām `role="search"` |
