# F3 — Mijiedarbību žurnāls: prasības apraksts

Oct 14, 2026 · @Arvīds Vilčaks

## Pamatinformācija

Darbinieks pieraksta katru saziņu ar organizāciju — zvanu, e-pastu vai tikšanos. Žurnāls parāda sadarbības vēsturi organizācijas kartītē, un F9 rāda pēdējās mijiedarbības un to skaitu šonedēļ.

| Lauks | Vērtība |
| --- | --- |
| ID | F3 |
| Nosaukums | Mijiedarbību žurnāls |
| Veids | Funkcionālā prasība |
| Statuss | Izpildīts (CR-7) |
| Atkarīga no | F0 (pieslēgšanās), N3 (lomas), F1 (organizācijas) |
| Izmanto | F9 (pēdējās mijiedarbības, kartīte „mijiedarbības šonedēļ”) |
| Jāatbilst | N1 (pieejamība), N2 (personas dati), N4 (tehnoloģijas) |

## Mērķis un lietotāji

| Loma | Ko redz / dara | Nolūks |
| --- | --- | --- |
| Darbinieks | Pievieno mijiedarbības jebkurai organizācijai; sarakstā `/mijiedarbibas` redz tikai savas | Uzturēt savu saziņas vēsturi |
| Vadītājs | Pievieno mijiedarbības; sarakstā redz visu darbinieku ierakstus ar darbinieka vārdu | Pārskatīt komandas aktivitāti |

Lauki: datums, veids (`zvans`, `e-pasts`, `tikšanās`), organizācija, darbinieks (vienmēr pieslēgtais lietotājs), kopsavilkums (līdz 2000 rakstzīmēm, nav obligāts).

## Pieejamība (N1)

- Tabulām `caption` („Manas mijiedarbības: N”, „Visu darbinieku mijiedarbības: N”, „Mijiedarbības ar …, jaunākās vispirms”) un `th scope="col"`.
- Veids rādīts tekstā („Zvans”, „E-pasts”, „Tikšanās”), datums formātā `DD.MM.GGGG`.
- Tukšam sarakstam paskaidrojums: „Mijiedarbību vēl nav.” / „Šonedēļ mijiedarbību nav.”
- Kartītes bloks ir `section` ar `aria-labelledby` uz `h2`.
- Formā izvēlnes ar etiķetēm, palīgteksti „Ne vēlāk kā šodien.” un „Līdz 2000 rakstzīmēm.”, kļūdu kopsavilkums ar `role="alert"`.

## Personas dati (N2)

- Kopsavilkums ir brīvs teksts, kurā var nonākt personas dati; tas tiek rādīts sarakstā un kartītē, bet ne F9 panelī.
- Darbinieka sarakstam filtrs `darbinieks_id = ?` tiek pielikts serverī. Organizācijas kartītē redzamas visu darbinieku mijiedarbības ar šo organizāciju.
- MI kopsavilkums un nākamā soļa ieteikums (MI-1) nav šīs prasības apjomā.

## Tehniskā realizācija (N4)

- **Maršruti:** `GET /mijiedarbibas?periods=sonedel` (HTML vai JSON pēc `Accept`), `POST /mijiedarbibas` (201/422), `GET /organizacijas/{id}/mijiedarbibas` (200/404) — aprakstīti `docs/openapi.yaml`; HTML palīgmaršruts `GET /mijiedarbibas/jauna?organizacija_id=`.
- **Atlase:** `atlasit(darbinieks_id, no, lidz, organizacija_id, limits)` — kopīga funkcija, ko izmanto arī F9; `redzamais_darbinieks()` nosaka lomas filtru; `sonedel()` izmanto `crm/laiks.py` (Europe/Riga).
- **Kartīte:** bloks reģistrēts `KARTITES_PAPILDINAJUMI` (F1).
- **Faili:** `crm/mijiedarbibas.py`, `crm/templates/mijiedarbibas/saraksts.html`, `forma.html`, `tabula.html`, `kartites_bloks.html`; tabula `mijiedarbibas` ar indeksiem pēc darbinieka un organizācijas.
- **Testi:** `tests/test_cr7_mijiedarbibas.py`.
