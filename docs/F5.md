# F5 — Uzdevumi un atgādinājumi: prasības apraksts

Oct 14, 2026 · @Arvīds Vilčaks

## Pamatinformācija

Uzdevumi (pirmā daļa) ieviesti ar CR-9. Šis apraksts aptver visu F5, ieskaitot otro daļu — atgādinājumus, kas realizēti bez atsevišķa CR.

| Lauks | Vērtība |
| --- | --- |
| ID | F5 |
| Nosaukums | Uzdevumi un atgādinājumi |
| Veids | Funkcionālā prasība |
| Statuss | Izpildīts (uzdevumi — CR-9; atgādinājumi — bez CR, 2026-10-14) |
| Atkarīga no | F0, N3; neobligāti F1 (organizācija) |
| Izmanto | F9 (bloki „Mani uzdevumi šodien” un „Atgādinājumi”), F6, F7 |
| Jāatbilst | N1, N2, N4 |

## Mērķis un lietotāji

| Loma | Ko var darīt |
| --- | --- |
| Darbinieks | Izveidot uzdevumu sev; redzēt savus; atzīmēt savu kā izpildītu; iestatīt atgādinājumu |
| Vadītājs | Redzēt visu uzdevumus; piešķirt uzdevumu jebkuram lietotājam; atzīmēt tikai savus |

## Lēmumi par atgādinājumiem

| Jautājums | Lēmums | Pamatojums |
| --- | --- | --- |
| Kāds ir atgādinājuma kanāls? | Paziņojums sistēmā: panelī bloks „Atgādinājumi” un atzīme „Atgādinājums” uzdevumu sarakstā | Minimāls apjoms; e-pasta sūtīšanai nav infrastruktūras, un tā prasītu papildu personas datu apstrādi |
| Cik atgādinājumu uzdevumam? | Viens — datums `atgadinat` | Pietiek ar „no kura datuma atgādināt” |
| Vai atgādinājums var būt pēc termiņa? | Nē, 422 | Pēc termiņa uzdevums jau ir blokā „Mani uzdevumi šodien” |
| Kad atgādinājums pazūd? | Kad uzdevums atzīmēts kā izpildīts | Nav jāpārvalda atsevišķs „noraidīts” stāvoklis |

## Detalizētās apakšprasības

| ID | Apakšprasība |
| --- | --- |
| F5.1 | Uzdevumam ir nosaukums (1–200), termiņš, neobligāta organizācija un atbildīgais (CR-9) |
| F5.2 | Atzīmēt kā izpildītu var tikai atbildīgais; PRG atpakaļ ar `role="status"` paziņojumu (CR-9) |
| F5.3 | Formā ir neobligāts lauks „Atgādināt no” (datums, ne vēlāk par termiņu) |
| F5.4 | Panelī bloks „Atgādinājumi” rāda paša lietotāja neizpildītos uzdevumus, kuru atgādinājuma datums ir šodien vai agrāk (Europe/Riga) |
| F5.5 | Uzdevumu tabulā aktīvajiem atgādinājumiem ir teksta atzīme „Atgādinājums” (ne tikai krāsa) |
| F5.6 | `GET /api/panelis` satur lauku `atgadinajumi`; `Uzdevums` — `atgadinat` un `atgadinajums_aktivs` |
| F5.7 | Tukšs bloks rāda „Atgādinājumu nav.” |

## Pieņemšanas kritēriji (atgādinājumi)

| # | Gadījums | Gaidāmais rezultāts |
| --- | --- | --- |
| 1 | Atgādinājums šodien, termiņš pēc 5 dienām | Redzams blokā „Atgādinājumi” |
| 2 | Atgādinājums rīt | Nav redzams |
| 3 | Uzdevums atzīmēts kā izpildīts | Pazūd no atgādinājumiem |
| 4 | Atgādinājums pēc termiņa | 422, kļūda pie lauka `atgadinat` |
| 5 | Cita darbinieka atgādinājumi | Nav redzami |

## Tehniskā realizācija (N4)

- `crm/uzdevumi.py`: `UzdevumsIevade.atgadinat` ar pārbaudi, `atlasit(..., atgadinajumi=True)`.
- Kolonna `uzdevumi.atgadinat` pievienota ar migrāciju `crm/db.py` `MIGRACIJAS`.
- `crm/panelis.py` un `templates/panelis/atgadinajumi.html`; sākumdatos atgādinājums ir 2 dienas pirms nākotnes termiņiem.
- Testi: `tests/test_cr9_uzdevumi.py`, `tests/test_prasibas_f2_n4.py` (`test_f5_*`).
