# F8 — Piekļūstamības paziņojums: prasības apraksts

Oct 14, 2026 · @Arvīds Vilčaks

## Pamatinformācija

Publiskas iestādes tīmekļvietnei jābūt piekļūstamības paziņojumam (MK noteikumi Nr. 445, Direktīva (ES) 2016/2102). F8 nodrošina šādu lapu CRM sistēmā.

| Lauks | Vērtība |
| --- | --- |
| ID | F8 |
| Nosaukums | Piekļūstamības paziņojums |
| Veids | Funkcionālā prasība |
| Statuss | Izpildīts (bez CR, 2026-10-14) |
| Saistīta ar | N1 (pieejamība) |

## Detalizētās apakšprasības

| ID | Apakšprasība |
| --- | --- |
| F8.1 | Lapa `/pieejamiba` pieejama bez pieslēgšanās |
| F8.2 | Saite „Piekļūstamības paziņojums” ir katras lapas kājenē (arī pieslēgšanās lapā) |
| F8.3 | Saturs: atbilstības statuss („daļēji atbilst”), nepiekļūstamā satura saraksts, izvērtēšanas metode, atsauksmju kontakti (e-pasts, tālrunis, atbildes termiņš), sūdzību iestāde, sagatavošanas un pārskatīšanas datumi |
| F8.4 | Lapai ir tāda pati struktūra kā pārējām (viens `h1`, sadaļām `h2`, orientieri) |

## Lēmumi

| Jautājums | Lēmums |
| --- | --- |
| Statuss | „Daļēji atbilst” — axe skenēšana vēl nav automatizēta (sk. N1) |
| Kontakti | Sintētiski (`pieejamiba@example.com`, `+371 60000000`), jo iestāde ir izdomāta |
| Pārskatīšana | Datumi konstantēs `crm/pieejamiba.py`; jāatjauno pēc katras būtiskas izmaiņas vai reizi gadā |

## Pieņemšanas kritēriji
