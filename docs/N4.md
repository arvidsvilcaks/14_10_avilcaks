## Prasības un realizācija

| ID | Prasība | Kā realizēts |
| --- | --- | --- |
| N4.1 | Steks | Python 3.12, FastAPI, Jinja2 šabloni, SQLite (lēmums CR-4) |
| N4.2 | API līgums | `docs/openapi.yaml` ir patiesības avots; visi JSON galapunkti tajā aprakstīti; `tests/test_ligums.py` pārbauda, ka līguma operācijas ir lietotnē un atbilst kursa noteikumiem (`400`, `404`, `5XX`, kopīgā `Error` shēma) |
| N4.3 | Laiks | „Šodien” = datums laika joslā Europe/Riga (`crm/laiks.py`); datumi glabājas ISO formātā `GGGG-MM-DD`; rādīti `DD.MM.GGGG` |
| N4.4 | Kavējumi un termiņi | Salīdzina ar Rīgas „šodien”: kavēts = termiņš < šodien (F9.7); atgādinājums aktīvs = datums ≤ šodien (F5) |
| N4.5 | Ātrums | Ar sākumdatiem (10 organizācijas, 20 kontakti, 30 mijiedarbības) panelis, kartīte, meklēšana, pārskats un prioritātes ielādējas < 1 s |
| N4.6 | Drošība | Visi SQL vaicājumi parametrizēti (`?`); lomu nolasa no datubāzes katrā pieprasījumā; POST–redirect–GET (303) formām; atpakaļ adreses tikai lokālas |
| N4.7 | Shēmas izmaiņas | `CREATE TABLE IF NOT EXISTS` + kolonnu migrācijas `db.MIGRACIJAS`, lai esošās datubāzes atjaunojas bez datu zuduma |
| N4.8 | Konfigurācija | Vides mainīgie: `CRM_DB_PATH`, `CRM_SESSION_SECRET`, `CRM_HTTPS`, `CRM_MACIBU_REZIMS`, `CRM_SAKUMDATU_PAROLE`, `CRM_MI_MODELIS`, `ANTHROPIC_API_KEY` |
| N4.9 | Pārbaudes | `make test` (pytest), `make lint-contract` |
