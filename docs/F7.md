# F7 — Pārskats vadītājam: prasības apraksts

Oct 14, 2026 · @Arvīds Vilčaks

## Pamatinformācija

F9 vadītāja blokā „Aktivitāte pa darbiniekiem” ir īss kopsavilkums par 7 dienām. F7 ir pilns pārskats ar izvēlamu periodu un sīkākiem rādītājiem. Uz to ved F9 saite „Atvērt pilnu pārskatu”.

| Lauks | Vērtība |
| --- | --- |
| ID | F7 |
| Nosaukums | Pārskats vadītājam |
| Veids | Funkcionālā prasība |
| Statuss | Izpildīts (bez CR, 2026-10-14) |
| Atkarīga no | F0, N3, F3, F4, F5 |
| Izmanto | F9.9 (saite no paneļa) |
| Jāatbilst | N1, N2, N4 |

## Lietotāji

Tikai vadītājs. Darbiniekam — 403. Navigācijā saite „Pārskats” redzama tikai vadītājam.

## Rādītāji katram darbiniekam

| Rādītājs | Periods |
| --- | --- |
| Zvani, e-pasti, tikšanās, mijiedarbības kopā | Izvēlētais periods (7, 30 vai 90 dienas; API 1–366), ieskaitot šodienu |
| Atvērtie pieprasījumi (nav „Atbildēts”) | Pašreizējais stāvoklis |
| Kavētie pieprasījumi (F9.7) | Pašreizējais stāvoklis |
| Neizpildītie uzdevumi | Pašreizējais stāvoklis |
| Kavētie uzdevumi (termiņš pirms šodienas) | Pašreizējais stāvoklis |

Pēdējā rinda „Kopā” summē visus darbiniekus.
