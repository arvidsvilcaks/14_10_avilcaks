# N2 — Personas dati (VDAR): prasības apraksts

Oct 14, 2026 · @Arvīds Vilčaks

## Pamatinformācija

CRM apstrādā personas datus: lietotāju (darbinieku) un kontaktpersonu vārdus, e-pastus un tālruņus. N2 nosaka, kā tos minimizēt, aizsargāt un pārvaldīt saskaņā ar VDAR.

| Lauks | Vērtība |
| --- | --- |
| ID | N2 |
| Nosaukums | Personas dati (VDAR) |
| Veids | Nefunkcionālā prasība |
| Statuss | Izpildīts (bez CR, 2026-10-14) |
| Attiecas uz | F0, F2, F3, F6, F9, MI-1, MI-2 |

## Prasības un realizācija

| ID | Prasība | Kā realizēts |
| --- | --- | --- |
| N2.1 | Datu minimizēšana | Kontaktpersonai tikai vārds, amats, darba e-pasts un tālrunis; formā atgādinājums |
| N2.2 | Panelī nerāda kontaktu e-pastus, tālruņus un mijiedarbību tekstu | `PanelaMijiedarbiba` bez kopsavilkuma un MI teksta; tests `test_n2_panelis_bez_kontaktu_datiem` |
| N2.3 | Piekļuves žurnāls | Organizācijas kartītes atvēršana un kontaktu saraksta nolasīšana ieraksta `piekluves_zurnals` (lietotājs, organizācija, laiks); paneļa atvēršana netiek žurnālēta |
| N2.4 | Žurnāla skatīšana | `/piekluves-zurnals` — tikai vadītājam (pēdējie 200 ieraksti) |
| N2.5 | Glabāšanas termiņš | Žurnāla ieraksti vecāki par 365 dienām tiek dzēsti, startējot lietotni (`db.inicializet`) |
| N2.6 | Labošana un dzēšana | Kontaktpersonas var labot un neatgriezeniski dzēst (F2); dzēsti dati uzreiz pazūd no kartītes, meklēšanas un paneļa |
| N2.7 | Piekļuves ierobežošana | Darbinieks redz tikai savas mijiedarbības, pieprasījumus un uzdevumus — arī meklēšanā; filtrs serverī (N3) |
| N2.8 | Ārēja apstrāde (MI-1) | Modelim sūta tikai mijiedarbības veidu un tekstu; lietotājs tiek brīdināts; rezultāts saglabājas tikai pēc apstiprinājuma |
| N2.9 | Paroles | PBKDF2 ar sāli; sesija parakstīta sīkdatne `HttpOnly`, `SameSite=Lax`, 8 h (F0) |
| N2.10 | Testu un sākumdati | Tikai sintētiski; e-pasti `example.com` domēnā |

## Lēmumi

| Jautājums | Lēmums |
| --- | --- |
| Ko žurnālēt? | Kartītes skatīšanu (tajā ir kontaktu dati), nevis katru sarakstu |
| Cik ilgi glabāt žurnālu? | 12 mēneši |
| Datu eksports (VDAR 15./20. pants)? | Ārpus minimālā apjoma; pieprasījumu izpilda administrators no datubāzes |
